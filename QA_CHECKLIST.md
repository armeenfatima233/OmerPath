# OmerPath QA Checklist

## Viewports
- 320px mobile
- 375px mobile
- 390px mobile
- 430px mobile
- 768px tablet
- 1024px laptop/tablet
- 1440px desktop

## Core journeys
1. Landing → Quick Match → Sign up → Onboarding → Scholarship matches.
2. Save scholarship → Open scholarship detail → Review fit and source status.
3. Applications → Move an application between Preparing / Ready / Submitted.
4. Passport → Add a local file → Create a simulated share link.
5. Advisor → Ask the three suggested questions and a custom question.
6. Profile → Edit values → Save → verify values appear in contextual views.
7. Notifications → mark one/all read.
8. Settings → change switches → reload and verify local persistence.
9. Reset prototype data in Settings.

## Accessibility
- Tab through all public and workspace controls.
- Confirm visible focus state.
- Confirm all icon-only controls have accessible labels.
- Test 200% browser zoom.
- Test `prefers-reduced-motion`.
